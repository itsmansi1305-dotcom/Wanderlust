# Wanderlust

Wanderlust is a travel accommodation listing web application where users can explore different places to stay, create their own listings, and share reviews.

## Features

- User registration and login
- Create, edit and delete accommodation listings
- Browse available listings
- View individual listing details
- Add and delete reviews
- Authentication and authorization
- Session management and flash messages
- Form validation and error handling

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- Bootstrap
- Passport.js
- HTML
- CSS
- JavaScript

## Installation and Setup

1. Clone this repository.
2. Install dependencies:

   npm install

3. Create a `.env` file in the root directory and add your configuration:

   SESSION_SECRET=your_secret_key
   MONGODB_URI=your_mongodb_connection_string

4. Start the application:

   node app.js

5. Open your browser at:

   http://localhost:8080
